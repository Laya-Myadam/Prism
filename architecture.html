Main Request Flow

  1. User works in the React app and sends page actions through frontend/src/api/client.ts.
  2. backend/main.py receives REST or streaming requests and dispatches to workflow services.
  3. Construction and property pages use Supabase-backed CRUD endpoints for records and approvals.
  4. Document and chat requests call domain engines, LangGraph agents, or the RAG pipeline.
  5. Agents use tools to read live project data, search documents, call LLMs, then return grounded answers.

Important Repo Files

  • frontend/src/App.tsx - route shell and app state
  • frontend/src/components/AICopilot.tsx - streaming assistant UI
  • backend/main.py - API surface
  • backend/agents/orchestrator.py - multi-agent router
